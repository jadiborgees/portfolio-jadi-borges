# Jadi Borges | Portfólio Web

Portfólio pessoal desenvolvido com foco em aplicações modernas, responsivas e experiências digitais profissionais.

---

## 🚀 Sobre o projeto

Este projeto foi desenvolvido para apresentar minhas habilidades como desenvolvedora web, incluindo projetos front-end, back-end, integração com APIs, arquitetura MVC e interfaces modernas.

O portfólio possui:

- Design tecnológico
- Layout responsivo
- Carrossel 3D de projetos
- Animações modernas
- Glassmorphism
- Estrutura MVC
- Integração com GitHub e LinkedIn
- Apresentação de projetos reais
